# Task Tracker

Двухкомпонентное приложение для управления задачами с админ-панелью и пользовательским интерфейсом.

## 📋 Описание

Проект состоит из двух частей:
1. **Админ-панель** - для управления пользователями и их задачами
2. **Пользовательское приложение** - для просмотра и отметки своих задач

## 🚀 Функционал

### Админ-панель
- Добавление новых пользователей
- Удаление пользователей
- Просмотр задач выбранного пользователя
- Создание задач для пользователей
- Отметка задач как выполненных
- Удаление задач

### Пользовательское приложение
- Авторизация по логину
- Просмотр своих задач
- Отметка задач как выполненных
- Автоматическое обновление списка задач
- Уведомления о новых задачах

## 🗄 Структура базы данных
### Таблица пользователей (todolist)
- user_id - ID пользователя (первичный ключ)
- username - Имя пользователя (уникальное)

### Таблица задач (tasks)
- task_id - ID задачи (первичный ключ)
- user_id - ID пользователя (внешний ключ)
- title - Название задачи
- date - Дата выполнения
- status - Статус (выполнено/не выполнено)
## 🛠 Технологии

- Python 3.x
- Tkinter (графический интерфейс)
- SQLite3 (база данных)
- Plyer (уведомления)
